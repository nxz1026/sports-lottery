# league-predict 全玩法覆盖分析报告（2026-09-15）

基线：GitHub main@60e3201（=mimir 部署）。本报告所有"实测"标注均为本机当日真实请求结果。

## 0. 体彩全玩法清单（目标域）

竞彩足球 6：胜平负 / 让球胜平负 / 总进球数 / 比分 / 半全场 / 混合过关（串关）
传统足彩 4：14场胜负 / 任选9 / 6场半全场 / 4场进球
竞彩篮球 3：胜负(含冠军赛制外) / 让分胜负 / 大小分（篮彩也有过关）
范围外建议：北单（SP 浮动、无公开数据源）、乐透数字彩（与赛事预测无关）

## 1. 算法需求（三层）

### 1.1 基本算法（概率内核——决定一切数字）
| 玩法 | 算法 | 现状 |
|---|---|---|
| 胜平负 | ELO+市场+Onside+DC | ✅ 已有 |
| 比分(31项) | DC 矩阵直接读取（0-8球+5+桶） | ✅ 矩阵已有，缺"官方选项映射" |
| 总进球数(8项) | 矩阵按 i+j 边际求和 | 🆕 纯推导，约几十行 |
| 让球胜平负 | 矩阵按净胜球+让球线移位求和 | 🆕 推导 + 竞彩让球线（数据问题见§2） |
| 4场进球数 | 每队进球边际分布（矩阵列/行边际） | 🆕 纯推导 |
| 半全场(9项)/6场半全场 | 上下半场分解：λ₁=w·λ, λ₂=(1-w)·λ，w 按联赛主客场从历史 halfTime 拟合；半场 DC 矩阵 × 下半场条件矩阵联合；ρ 分别校正 | 🆕 唯一的新概率模型（数据已免费实测可得） |
| 14场/任9 | 单场模型 + 期号赛程圈选 + 冷门/平局概率排序（做胆材/博冷推荐） | 模型复用，赛程圈选是数据活 |
| 混合过关/串关 | 期望值 + Kelly 仓位 + 场次相关性修正（同轮/同队伤病传染）；组合枚举剪枝 | 🆕 独立小模块 |
| 奖级/头奖滚存预估 | 热门度反推（官方赔率隐含概率分布）× 销量 → 奖级期望 | 🆕 依赖官方人气数据 |
| 篮球 让分/大小分 | 现有点估计+置信门 → 升级为 P(cover)=Φ(净胜分/σ)、σ 由历史回归残差估计 | 🆕 小改 |
| 冠军/冠亚军 | 蒙特卡洛赛季模拟 | ✅ 已有（淘汰赛对阵表已实现） |

### 1.2 ML（只补基本算法证伪后的短板）
- 现状：26 维特征 + softmax 逻辑回归按联赛训练（--train-ml 已有）。
- 值得新增：①总进球/比分残差修正（DC 低比分段系统性偏差，GBDT/有序 logistic）；②任9 冷门二分类（赔率移动幅度、跨联赛、休息日、轮换信号）；③篮球 margin/total 回归（把 0.3ELO+0.7market 线性融合换成模型）。
- 制约：免费 API 历史窗口 2022–2024（实测），五大联赛 ≈5700 场可用，小联赛样本稀；训练数据落盘（results/ 已有积累机制），ML 特征向量已在 features.py 就绪。

### 1.3 AI 分析（LLM——只做解释与决策辅助，禁止产出数字）
- 现状：enrich.py 中文日报摘要 + ai_score（已修串位/类型崩溃，M6/M8 系列）。
- 新增：①逐场分析报告（矩阵+特征→人话）；②14场"胆材/博冷/防平"叙事（输入=基本层概率，LLM 只做理由归纳与风险提示）；③开奖复盘（自动回填结果→错场归因）；④自然语言出票（文本→约束→串关优化器）。
- 平台约束：Hobby scale-to-zero，冷启首请求慢；LLM key 走 runtime.env，配额与预测共享。

## 2. 数据源充足性（实测结论，不到万不得已不爬虫）

| 需求 | 源 | 实测结果 | 判定 |
|---|---|---|---|
| 足球赔率(1X2/亚盘/大小) | API-Football /odds | 免费 key 当日 10 场返回 pre-match odds | ✅ 够用 |
| 半场比分(训练+验奖) | football-data v4 / API-Football | FD 380/380 FINISHED 含 score.halTime；AF 380/380 含 score.halftime | ✅ 免费可得 |
| 历史赛季(小联赛期号) | API-Football | 免费仅 2022–2024（"Free plans do not have access to this season"），100 req/天 | ⚠️ 期号含北欧/日韩等，联盟覆盖有、历史短 |
| 篮彩盘口 | The Odds API | 免费 500 credits/月，h2h/spreads/totals | ✅ 让分/大小可用；与竞彩官方让分线存在 ±0.5/整分口径差 |
| **竞彩官方让球线、固定奖金、奖期、开奖** | webapi.sporttery.cn（官网 JSON 网关） | 日/美 IP 直连被挡（实测 HTTP 567 + 反爬页），zgzcw 等第三方为页面爬取 | ❌ **唯一硬缺口**：需国内出口（代理/家宽 ECS）才能"调官方接口"而非爬虫 |
| 任9/14场人气分布(奖级预估) | 同上 sporttery | 同上 | ❌ 依赖国内出口 |
| 阵容/轮换特征 | API-Football /lineups | 未实测 | ❓ 待测免费配额 |

结论：**算法侧原料已 90% 足够（不爬虫）；唯一结构性缺口是"中国体彩官方口径数据"（让球线、奖期赛程、固定奖金、开奖、销量人气），它决定 P2 层玩法（让球胜平负/传统足彩/奖级预估）能不能做准**。无国内出口时的降级方案：让球线用竞彩开售惯例（从国际盘口换算近似，半全场/总进球可全做），14场/任9 用 API-Football 全联盟 fixture 按官方公告人工核对圈选。

## 3. 功能重叠与独立链路

**高重叠（复用现链，只加薄层）**：胜平负、比分、总进球、4场进球、让球 → 全部是同一张 DC 矩阵的"读法"；串关/过关 → 挂在概率输出后的独立优化器；AI 摘要、回测、校准、cron、登录、FastAPI Cloud 部署链 → 全玩法共享。
**中度独立**：半场分解模型（新概率件，但 λ/ρ/ELO 特征全复用）；篮彩链（独立 ELO/数据源/UI，仅共用 web 壳与 LLM 摘要）。
**完全独立、新增链路**：奖期圈选与开售日历（期号 ≠ 五大联赛，涉及全联盟调度 + 中文队名映射扩展，COUNTRY_CN 目前只覆盖五大+中超，小联赛队名翻译是隐性工作量）；官方固定奖金/开奖核对（需国内出口）；奖级分布预估。
**重叠风险点**：predict.py CLI、web job、cron 三者并行取数路径已存在（datasource.py/refresh_job/cron 有重叠），玩法扩容前建议先统一"取数→矩阵→派生→缓存"单向数据流，避免每玩法各抄一份。

## 4. 优先级建议（按边际成本）
- P0（纯代码、零新数据）：派生层（总进球/比分映射/4场进球）+ 串关优化器 + 篮球 P(cover)
- P1：半场分解模型（数据免费已验证）→ 解锁半全场、6场半全场
- P2（依赖国内出口决策）：奖期圈选 + 官方让球线/奖级 → 解锁让球胜平负官方版、14场、任9
- 建议排除：北单、乐透数字彩

## 5. 用户拍板结果（2026-09-15 确认）
1. **范围**：竞彩足球 6 + 传统足彩 4 + 篮彩 3；北单、乐透数字彩排除。
2. **无国内出口 → 降级方案**：让球线由国际盘（API-Football AH）换算成竞彩整数线；奖期按规则圈选候选 + 每周人工核对官方公告；开奖核对自建（赛果自取算中奖注数），官方奖金额不做、用奖级结构+历史中奖分布近似。
3. **数据**：先用免费档（API-Football 2022–2024 + FD 全量 halfTime + Odds API 500/月），证明确认缺历史再付费。
4. **串关形态**：推荐组合 + EV 报告，不做投注单 UI。

## 6. 定稿路线图（降级口径）

### P0 派生层与优化器（纯代码，零新数据）
- `markets` 派生模块：DC 矩阵 → 竞彩比分 31 项映射 / 总进球 8 档 / 让球（线参数化，AH→整数线换算器）/ 4场进球每队档位；14场/任9 的每场三向概率直读现有输出
- 串关 EV 优化器：去水概率 × 竞彩固定奖金近似 → Kelly 仓位、相关性修正、Top-N 组合报告（无票单 UI）
- 篮彩：P(cover)=Φ(margin/σ) 回归 σ，输出让分/大小置信度（升级现有置信门）
- 取数链统一：predict.py / web job / cron 三路并流为一条"取数→矩阵→派生→缓存"
- 验收：backtest.py 复跑，派生层单测逐玩法对账（矩阵边际和=1、让球移位边界）

### P1 半场链路（数据已实测免费可用）
- 按联赛×主客拟合半场占比 w（FD halfTime，2022–2024 五大联赛 ~5700 场）
- 半场 DC（各自 ρ）× 下半场条件联合 → 半全场 9 项 / 6场半全场
- 可选 ML：比分低段残差修正、任9 冷门二分类（休息日/跨联赛/盘口移动特征）

### P2 奖期系统（传统足彩，降级口径）
- 期号候选圈选器（周末轮/周五六日模板，API-Football 全联盟 fixtures）+ 人工周检
- 小联赛队名中文映射扩展（期号池联赛清单驱动）
- 中奖核对：自取赛果 → 任14/任9/6场/4场中奖注数统计；奖金近似模型（无官方销量）

### 已知未实测项（实施首周补验）
- API-Football /lineups 免费配额（影响轮换特征，P1 ML 增强才需要）
- 竞彩 AH→整数线换算的误差量化（拿 2–3 期官方让球线人工对照）
