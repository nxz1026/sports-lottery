## `.done` 第三列"级联哈希"算法定义

`sha256( 逐行 utf-8 字节按文件内顺序直接拼接 )`，即对 `.jsonl` 每个非空行（去尾部换行后）的 utf-8 字节依次喂入同一个 `sha256`，最后取十六进制 digest。`.empty` 文件第三列留空。

Python 实现（`collector.py:_manifest`）：
```python
h = hashlib.sha256()
for line in open(path, encoding="utf-8"):
    line = line.strip()
    if not line:
        continue
    h.update(line.encode("utf-8"))
cascade = h.hexdigest()
```
复算方式：远端对清单里每个文件按同样规则算一遍，与清单第三列比对。行数与 `src_hash`（每行 `payload` 的官方式哈希）是独立校验列，级联哈希只验字节完整性（防截断/乱序）。
